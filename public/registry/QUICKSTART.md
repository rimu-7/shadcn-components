# Quick Install

```bash
npx shadcn@latest add text-writing-effect -r https://raw.githubusercontent.com/rimu-7/shadcn-components/main/public/registry/index.json
```

Or with your package manager:

```bash
# npm
npx shadcn@latest add text-writing-effect -r https://raw.githubusercontent.com/rimu-7/shadcn-components/main/public/registry/index.json

# pnpm  
pnpm dlx shadcn@latest add text-writing-effect -r https://raw.githubusercontent.com/rimu-7/shadcn-components/main/public/registry/index.json

# yarn
yarn dlx shadcn@latest add text-writing-effect -r https://raw.githubusercontent.com/rimu-7/shadcn-components/main/public/registry/index.json

# bun
bunx shadcn@latest add text-writing-effect -r https://raw.githubusercontent.com/rimu-7/shadcn-components/main/public/registry/index.json
```
